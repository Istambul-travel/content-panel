Panel'i GitHub'a bağla

Panel verileri doğrudan repo'dan okur ve değişikliklerini oraya yazar. Anahtar sadece bu tarayıcıda saklanır, hiçbir sunucuya gitmez.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → travelpedia-content-engine
  3. Permissions: Contents: Read and write, Actions: Read and write, Metadata: Read
  4. Anahtarı aşağıya yapıştır
